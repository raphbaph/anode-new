Topic 1005 - RC V15.0 Release Note (General)

Eleanor posted the official release note for RC V15.0. The summary states that the Rootstock Collective Foundation released V15.0, a version that makes rewards data faster and more dependable. Rewards figures across the dApp now load from the Collective's own indexed data instead of repeated explorer queries, and the dApp's connection to the explorer is more secure. The post closes with a pointer to access the latest version.
